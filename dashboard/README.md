# Retail Intelligence Dashboard

React + Vite + Recharts + Tailwind dashboard for Edge AI Retail Intelligence.

## Features
- Real-time footfall & occupancy monitor
- Queue length & wait time predictor per checkout lane
- Shelf out-of-stock and low-stock alerts
- Heatmap visualization overlay
- Daily / weekly KPI reporting

Built for offline-first local deployment with optional central multi-store view.
